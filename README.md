## 项目简介

天机阁是一款基于中国传统玄学体系的在线命理预测 Web 应用。用户输入个人出生信息后，系统通过天干地支、四柱八字、五行生克、洛书九宫等传统命理学算法，生成专属命盘与运势分析。整体采用暗紫黑底 + 金色强调的玄幻视觉风格，配合丰富的粒子动画与占卜动效，提供沉浸式的玄学体验。

## 核心功能

### 命盘推演
- **四柱八字排盘** — 根据出生年月日时推算年柱、月柱、日柱、时柱的天干地支
- **五行分布分析** — 统计金木水火土在命局中的占比，识别最旺与最弱五行
- **本命卦推算** — 依洛书九宫与出生年性别推排命卦，判定命格基本格局
- **流年运势** — 事业运、财富运、感情运、健康运、学业运五大维度综合评分
- **每日宜忌** — 基于命盘推演当日适宜与应避免之事
- **命理推演过程** — 五步推演详解（排定四柱 → 剖析五行 → 判定日主 → 推算命卦 → 综合论断）

### 事情预测
- 用户输入近期打算做的一件事（如考研、创业、表白等），结合命盘推演成功率
- 支持选择事情类别（学业考试、求职面试、创业投资等 9 类）和计划时间
- 输出成功率、命理分析、关键因素、吉祥时辰、吉利方位、天机建议

### 个人信息采集
- 必填项：姓名、性别、出生日期（年/月/日下拉选择）、出生时辰（十二时辰）
- 选填项：出生地、血型、星座、婚姻状态、学历、毕业年份、职业、兴趣爱好、幸运数字、现居地、手机尾号、梦想职业、近期状态

## 命理算法说明

### 四柱推算
- **年柱**：以出生年份对天干（10）和地支（12）取模
- **月柱**：依"年上起月法"，根据年干确定月干起始
- **日柱**：以 2000 年 1 月 7 日（庚子日）为基准日推算偏移
- **时柱**：取用户选择的十二时辰地支

### 五行分析
- 天干地支各有对应五行属性，统计七个字（六干支 + 时支）的五行分布
- 归一化为百分比，识别最旺与最弱五行
- 结合纳音五行判断日主旺衰

### 命卦推算
- 男命：(100 - 出生年) % 9
- 女命：(出生年 - 4) % 9
- 映射至洛书九宫对应的八卦与五行

### 运势评分
- 基于所有输入信息的确定性哈希生成 0-100 分数
- 五大运势加权平均：事业运 25%、财富运 20%、感情运 15%、健康运 20%、学业运 20%
